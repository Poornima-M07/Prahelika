

# Prahelika

Prahelika is a sleek and sophisticated web application for encoding and decoding text using a variety of classic ciphers. With a user-friendly interface for cryptographic transformations, its name derives from the Sanskrit word for "riddle" or "puzzle," reflecting the app's core function.

## ✨ Features

*   **Multiple Ciphers:** Supports a wide range of encoding and decoding algorithms.
*   **Dual Mode:** Easily switch between `Encode` and `Decode` operations.
*   **Auto-Detection:** Intelligently detects the cipher type of the input text for certain formats.
*   **Interactive Controls:** Adjust cipher-specific options, such as the rotation shift for the Caesar cipher or the key for the Vigenère cipher.
*   **Elegant UI:** A modern, responsive interface built with React and Tailwind CSS featuring a unique "rose-gold on onyx" theme.
*   **Copy to Clipboard:** Quickly copy the transformed output with a single click.

## 🛡️ Ciphers Supported

*   Auto-Detect
*   Base64
*   ROT13
*   Caesar Cipher
*   Vigenère Cipher
*   Atbash Cipher
*   Hexadecimal
*   Binary
*   Morse Code
